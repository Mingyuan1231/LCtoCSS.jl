# LCToCSS.jl

Polynomial-time local-Clifford conversion of stabilizer codes to CSS form,
implemented in Julia with a QuantumClifford.jl interface.

`lc_to_css` chooses compatible local Pauli axes, applies single-qubit Cliffords,
and extracts signed pure-X and pure-Z checks. It supports stabilizer states and
codes with logical qubits. The affine recognition algorithm is based on
*Local Clifford equivalence to CSS codes: Polynomial-time recognition and
conversion* by Mingyuan Wang, with the accompanying Python implementation in
[LCtoCSS](https://github.com/Mingyuan1231/LCtoCSS).

## Installation

Use Julia 1.12 or later. Install from GitHub:

```julia
using Pkg
Pkg.add(url="https://github.com/Mingyuan1231/LCtoCSS.jl")
```

The runtime dependencies are QuantumClifford.jl and Julia's SparseArrays
standard library. The package and its tests do not require Python. Reference
inputs are included in the test fixtures.

To run the tests and example from a local checkout:

```sh
git clone https://github.com/Mingyuan1231/LCtoCSS.jl.git
cd LCtoCSS.jl
julia --project=. -e 'using Pkg; Pkg.instantiate(); Pkg.test()'
julia --project=. examples/basic.jl
```

## Convert a stabilizer

```julia
using QuantumClifford, LCToCSS

s = S"XZ
      ZX"
result = lc_to_css(s; positive=true)
if result !== nothing
    result.checks        # +XX and +ZZ for this example
    result.hx            # binary X checks
    result.hz            # binary Z checks
    result.circuit       # native gates in execution order
    result.generator_map # K: output generators as products of input images
end
```

The input is never mutated. A `nothing` result means no local Clifford
conversion exists. Noncommuting generators, imaginary phases, and inconsistent
signed relations (including `-I`) raise `ArgumentError`.

Apply the returned circuit to a copy of the input:

```julia
t = copy(s)
for gate in result.circuit
    apply!(t, gate)
end
@assert t == result.transformed
```

The transformed generators can still contain mixed X/Z rows. Their signed
group equals that generated by `result.checks`; `generator_map` records the
required change of generators as a sparse Boolean matrix. Its nonzeros refer
to at most an independent input subset, avoiding a dense square relation map
for heavily redundant inputs. Qubit order is preserved.

### Options and signs

`positive=false` preserves the physical signs produced by the chosen Clifford
lift. `positive=true` appends a local Pauli correction to the circuit so all
output checks have positive signs; that Pauli is also returned as `correction`.
Signs of projected checks are recovered by multiplying transformed generators.
For example, `+YY` and `+ZZ` generate `-XX`, so copying signs through a binary
projection would give an incorrect code space.

`independent=true` selects independent checks from the nonzero projections of
the supplied transformed rows. It returns exactly the input rank in checks.
`independent=false` retains every nonzero projection, including duplicates.
Both options retain the check-weight bound of the supplied generators. The
second option returns at most `2m` checks and at most twice the input qubit
incidence, where `m` is the supplied row count.

For a mixed or destabilizer tableau, pass `stabilizerview(state)` explicitly.
The returned circuit can also be applied to logical operators in the chosen
frame. The API does not mutate or reconstruct a destabilizer tableau.

### Binary recognition and coordinates

```julia
witness = css_witness(x, z) # equal-sized AbstractMatrix{Bool} inputs
accepted = is_lc_css(x, z)
accepted = is_lc_css(s)    # also validates the signed stabilizer group
```

The binary API accepts redundant and zero rows, unused qubits, and zero qubits.
It ignores phases by design. `CSSWitness` contains `local_maps`, `rank`,
`factors`, and the successful anchor `branches`.

`local_maps[i] = (a,b,c,d)` represents the right-acting matrix `[a b; c d]`:

```text
(x,z) -> (x*a XOR z*c, x*b XOR z*d)
```

QuantumClifford's `stab_to_gf2` uses grouped columns `(x | z)`. The recognition
core explicitly interleaves these coordinates for factor decomposition. Julia
indices are one-based. Circuit entries are in execution order, so applying S
then H represents the unitary H*S. No unique representative of an LC orbit is
claimed.

### Syndrome conversion

For exact syndrome bits relative to the supplied signed generators:

```julia
css_syndrome = isodd.(result.generator_map * Int.(input_syndrome))
```

For an error label, apply `witness.local_maps` to each `(x_i,z_i)` pair. The
Pauli correction does not change binary error labels. For syndrome bits
measured against unsigned Pauli representatives, add the known input sign
bits first. This interface does not prescribe a decoder or noise model.

## Algorithm and integration

The core obtains an interleaved RREF basis, decomposes its physical support
factors, and solves the preservation equations for trace-one local blocks
`P_i = [a_i b_i; c_i 1+a_i]`. Each factor tries `b_1=0`, then `c_1=0` if
needed. These branches enforce idempotence on the entire factor. Image and
kernel vectors of each projector give its local Clifford map.

The ordinary GF(2) solver uses contiguous UInt64-packed rows and does not
assume commutativity of auxiliary equations. The recognition bound is
`O(m*n^2 + n^4)` scalar binary operations and `O(m*n + n^3)` bits, before
container overhead. The implementation is deterministic and uses no
exponential local-Clifford search. Exhaustive searches occur only in tests.

See [the QuantumClifford interface](docs/quantumclifford-integration.md)
for the module boundaries, native operations, and return semantics.

## Validation

The [test suite](docs/validation.md), run with `Pkg.test()`, includes:

- Independent scalar elimination versus the packed GF(2) solver, including
  inconsistent systems and word boundaries at 63/64/65 and 127/128/129 bits.
- Literal local-Clifford search on all 550 isotropic spaces through three
  qubits and independent LC-orbit enumeration on all 1,100 graphs through
  five vertices.
- All 1,136 saved reference decisions, including 1,034 positive witnesses.
- Signed-group equality, real-unitary checks of all six local lifts, redundant
  sign relations, positive correction, exact syndrome maps, sparse bounds,
  factor separation, and a case requiring the second anchor branch.
- Connected instances through 128 qubits and signed BB inputs on 72, 144,
  and 288 qubits.

Finite tests validate the implementation; the polynomial-time correctness
argument is the projector and factor theorem in the paper. Failure is returned
as `nothing`; this API does not serialize independently checkable negative
certificates. It also does not implement the separate adjacency-specialized
bipartite representative algorithm.
